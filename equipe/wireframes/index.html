Legenda

  • Etiqueta preta = código da seção (ex. H-02) + componente reutilizável (Cxx, ver 02-wireframe.md §4).
  • Etiqueta tracejada = seção condicional/opcional: só entra com dado real.
  • [Colchetes] = placeholder para o copywriter; [A CONFIRMAR] = dado do cliente pendente, nunca inventar.
  • Caixa cinza com nota = comportamento mobile, asset real a usar (ASSET), ou FOTOGRAFAR / PEDIR / GERAR / CRIAR.
  • Botão “Ocultar notas” na barra preta mostra o wireframe limpo.
